# fmcg-Store-Sales-Analysis — SQL Project

> Exploratory data analysis of a 1,000-row FMCG (Fast-Moving Consumer Goods) retail dataset using MySQL. Uncovers revenue trends, top-performing products, regional order patterns, and company-level performance metrics.

---

## Project Overview

This project analyzes sales data from an FMCG store market dataset spanning multiple Indian consumer goods companies, product categories, regions, and sales channels. The goal is to extract actionable business insights using structured SQL queries.

**Dataset size:** 1,000 rows | **Tool:** MySQL Workbench | **Database:** `fmcg
---
## Dataset Columns

| Column | Description |

| `Company` | FMCG brand name (e.g., ITC, HUL, Dabur) |
| `Category` | Product category (Health Care, Food & Beverages, etc.) |
| `Subcategory` | Specific product type (Soap, Hair Oil, etc.) |
| `Region` | Sales region (North, South, East, West) |
| `Sales_Channel` | Online / Offline |
| `Year` | Transaction year |
| `Revenue_USD_Million` | Revenue in USD millions |
| `Market_Share_%` | Market share percentage |
| `Growth_%` | Year-over-year growth |
| `Urban_Rural` | Customer location type
